Build a small browser-based team task tracker using the existing project stack.

Required behavior:
- Add a task with a non-empty title and optional owner.
- Toggle a task between open and complete.
- Filter tasks by all, open, or complete.
- Preserve tasks across a page refresh using local storage.
- Provide an accessible label for every form control.
- Add deterministic automated tests for the task state behavior.
- Document the exact local build, test, and launch commands.

Do not add a remote service or authentication.
